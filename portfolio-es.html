Predicción de Marketing Bancario

Proyecto de machine learning para predecir si un cliente aceptará la oferta de campaña de un banco, usando datos reales.

Python Pandas Scikit-learn Matplotlib Jupyter
Ver más

Objetivo: Construir un modelo de clasificación para predecir la probabilidad de aceptación de una campaña telefónica.

Preprocesamiento: Codificación de variables categóricas, normalización, eliminación de fuga de información (variable 'duration').

Selección de modelo: Comparación de Random Forest con y sin 'duration'.

Evaluación: El modelo sin 'duration' es más ético y realista, con F1 equilibrado.

Insight: Menor exactitud, pero mayor aplicabilidad en la vida real.
